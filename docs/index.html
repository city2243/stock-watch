公司 看法 現價 便宜價 可買價 E(TP) 距可買價 價位在哪一區 模型日

區間怎麼算

  • 便宜價=E(TP)÷1.3(空間 30% 以上,「買進區」:滿部位分三批);可買價=E(TP)÷1.2(空間 20–30%,「加碼區」:半部位分兩批)。
  • 可買價到 E(TP)×0.9 是觀望;E(TP)×0.9 到 E(TP) 減碼;超過 E(TP) 到樂觀價是超過目標;樂觀價以上出清。
  • 風險區=跌破悲觀情境價:不是停損點,先逐條核翻轉條件;沒翻=市場在定價悲觀情境,照買進區規則;翻了就出清。
  • 評等是減碼的,到價也不買——先 refresh 模型。模型超過 45 天沒更新標「過期」,買之前先 refresh。
  • E(TP) 是各案 12 個月機率加權目標價;邊界 ÷1.3、÷1.2、×0.9 是事先定的規則,還沒有回測。與操作卡同一套。
  • 股價每個交易日收盤後自動更新(台股/日股傍晚、美股隔天清晨);新進可買區間會在 GitHub 開 issue 通知。
